BEFORE PUBLISHING:
1. Open index.html in a text editor.
2. Replace both href="#" Airbnb links with your actual Airbnb listing URL.
3. Replace 91XXXXXXXXXX with your WhatsApp number.
4. Update the locality, amenities and parking statement if needed.

FREE HOSTING — GITHUB PAGES:
1. Create a GitHub account.
2. Create a PUBLIC repository, e.g. 3bhk-luxe-apartment.
3. Upload all files in this folder.
4. Repository Settings -> Pages.
5. Select "Deploy from a branch", branch "main", folder "/ (root)".
6. Save. GitHub will provide your website address.

You can later connect a custom domain such as www.yourdomain.com.
